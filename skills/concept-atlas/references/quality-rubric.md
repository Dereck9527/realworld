# Quality rubric

Review each item before delivery. A structural validator pass is necessary but never sufficient.

| Gate | Pass condition |
|---|---|
| Identity | The intended sense/context is explicit; material ambiguity was asked or assumed visibly. |
| Evidence | Consequential claims have ledger links and inspected direct sources; priority claims are triangulated where feasible. |
| History | Roles are separated; chronology does not substitute for contribution analysis. |
| Transfer | Cross-domain borrowing names both domains and semantic/methodological change. |
| Current use | Meanings, applications, and communities are distinguished and bounded by the cutoff. |
| Learning | Prerequisites are ordered for a novice and distinguish common confusions. |
| Epistemics | Event and publication dates are not conflated; uncertainty, inference, and disputes are visible. |
| Contract | Exact report headings, ledger, direct reference URLs, mode, and cutoff are present. |

If any evidence gate fails, reduce the claim, add a limitation, research further, or issue a truthful provisional output. Never use confidence styling to conceal unsupported content.
